# The AlkanOdyssey v1.0.0

An HTML5 pixel-art educational adventure that teaches IUPAC alkane naming through exploration, puzzles, and a chemistry-based final boss.

## Learning objectives

- Find the longest carbon chain.
- Number carbon atoms for the lowest locant.
- Identify alkyl substituents.
- Apply alphabetical ordering and complete IUPAC names.

## Launch

Open `index.html` in a modern desktop browser. No installation, server, or external libraries are required.

## Controls

`A/D` or arrows move · `Space` jump · `Shift` run · `E` interact · `J` journal · `I` inventory · `M` map · `V` abilities · `Esc` pause.

## Project structure

- `index.html`, `style.css`, `script.js` — application shell and gameplay
- `*-manager.js` — scene, quest, save, puzzle, boss, final-exam, demo, tutorial, and achievement systems
- `assets/sprites.svg` — local sprite atlas
- `levels/`, `data/` — chapter and chemistry data

## Educational features

Five chapters progress from straight-chain alkanes to a final naming exam. Journal entries, feedback, statistics, achievements, and Demo Mode support classroom and competition use.

## Credits

Built with HTML5 Canvas, CSS3, and JavaScript ES6. Local artwork is a project sprite atlas; audio is synthesized with Web Audio.
